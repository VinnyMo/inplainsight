What happens to my file?

Your file is uploaded and processed on the server, which stores the keys needed for recovery.

An optional password adds protection. Your browser derives a key and sends that key to the server; the password itself isn't sent.

Expiry cleanup runs on a schedule, so deletion isn't exact to the minute. Downloading images or adding a password doesn't extend recovery time.

This is not offline storage or end-to-end encryption.
